# 실행 명세 · 뇌척수액 펩타이드의 소수성 패턴 비교

2026-11-23 개정 · 프로그래밍기반 데이터 분석

## 연구 질문과 입력

이번 측정에서 알츠하이머 치매군(AD)에서만 검출된 서열과 정상 대조군(Control)·경도인지장애군(MCI)·AD 세 집단에서 공통 검출된 서열은 소수성 잔기의 비율과 최장 연속 길이에서 어떤 차이를 보이는가?

입력은 공개 연구의 **Supplemental Table 7** 엑셀 파일이다. 연구진은 집단마다 16명의 뇌척수액을 합쳐 측정했다. 분석 단위는 고유한 기본 펩타이드 서열이다. 각 집단에서 검출됐다는 표시는 해당 집단의 혼합 시료에 관한 관측값이다. 개인별 빈도, 질병의 원인, 응집 여부는 이 측정으로 판단할 수 없다. [논문 및 보충표](https://pmc.ncbi.nlm.nih.gov/articles/PMC9240109/)

## 핵심 기능

1. **입력 정리.** 실제 시트와 열을 확인해 기본 서열과 검출 집단을 연결한다. 변형 정보는 별도로 보존한다. 기본 서열의 공백을 제거하고 대문자로 통일한다. 빈 서열, 표준 20종 외 문자, 판독하기 어려운 변형 표기는 사유와 함께 제외 기록에 남긴다. 필수 열이나 집단을 식별할 수 없으면 해당 위치를 안내한다.
2. **검출 조합 분류.** 같은 집단에서 기본 서열이 반복되면 한 번만 센다. 같은 서열이 여러 집단에 있으면 검출 표시를 모두 유지한다. 결과표 한 행은 고유 서열 하나이며, 각 행은 세 집단으로 만들 수 있는 일곱 검출 조합 중 하나에 속한다.
3. **서열 특성 계산.** 길이, 아미노산 20종별 개수, 소수성·친수성 잔기 수와 비율, 최장 연속 소수성 잔기 수를 구한다. 비율의 분모는 기본 서열 길이다. 초기 기획의 Kyte–Doolittle 지수 부호를 쓰는 프로젝트용 이분류안을 기준으로 하되 구현 전에 표준 20종 분류표를 확인해 공개한다. 변형에 따른 물성 변화는 계산 범위 밖이다.
4. **비교와 출력.** 고유 서열별 CSV에 기본 서열, 세 집단의 검출 표시, 검출 조합, 계산 지표를 저장한다. 조합별 서열 수와 두 주 비교 집단의 지표 분포를 그린다. 점 하나는 서열 하나다. 각 그래프에 해당 서열 수와 중앙값을 표시하고, 같은 길이 범위를 양쪽에 적용한 뒤 다시 비교한다. 빈 그룹은 서열 수 0, 중앙값은 결측으로 표시한다.

## 손검산과 완료 기준

아래 값은 구현 전 확인용 기대값이다. L은 소수성, S는 친수성으로 센다.

| 기본 서열 | 길이 | 소수성 잔기 수 | 소수성 비율 | 최장 연속 길이 |
| --- | ---: | ---: | ---: | ---: |
| LLLLSSSS | 8 | 4 | 50% | 4 |
| LSLSLSLS | 8 | 4 | 50% | 1 |
| SSSS | 4 | 0 | 0% | 0 |
| LLLL | 4 | 4 | 100% | 4 |

- 빈 서열과 허용되지 않은 문자가 포함된 서열은 제외 기록에 남고 분포 그래프에서 빠져야 한다.
- 같은 서열이 AD에 두 번, Control에 한 번 있으면 결과표 한 행에 AD와 Control만 표시돼야 한다.
- 각 서열의 아미노산별 개수 합은 서열 길이와 같아야 한다. 일곱 조합의 합은 전체 고유 서열 수와 같아야 한다.
- 동일한 길이 필터를 적용한 CSV 행 수와 그래프에 표시한 서열 수가 일치해야 한다.
