# 단백질 서열의 소수성·친수성 아미노산 조성 비교

여러 단백질에서 소수성·친수성 아미노산은 각각 몇 퍼센트를 차지하며, 두 비율의 차이는 서열마다 어떻게 달라질까? 이 프로젝트에서는 하나의 FASTA 파일에 담긴 단백질들을 읽고, 각 서열의 아미노산 조성을 표와 그래프로 비교하는 Python 프로그램을 기획했다.

**진행 상태** · 프로젝트 명세 작성과 기획 발표를 마쳤다. 다음 단계는 분류표 확정, 프로그램 구현, 예시 서열을 이용한 검증이다.

## 입력과 유효성 검사

- 여러 단백질 서열을 담은 FASTA 파일 한 개를 입력한다. 각 레코드에서 `>`로 시작하는 헤더의 ID를 읽고, 다음 헤더 전까지의 서열 줄을 이어 붙인다.
- 입력 순서대로 `input_order`를 부여한다. 같은 ID가 여러 번 등장해도 각 레코드를 독립적으로 처리한다.
- 서열에서 공백과 줄바꿈을 제거하고 소문자를 대문자로 바꾼다.
- 정리한 서열이 비어 있거나 표준 아미노산 20종 이외의 문자(숫자, `-`, `*` 등)가 하나라도 있으면 해당 레코드를 `invalid`로 표시한다. 다른 레코드는 계속 분석한다.

## 분류와 계산

발표에서는 Kyte–Doolittle 소수성 지수를 기준으로 삼았다. 구현 전에는 양수를 소수성, 음수를 친수성으로 묶는 **프로젝트용 이분류 규칙**을 검토하고, G·P·C를 포함한 표준 20종의 원래 지수값과 최종 분류를 표로 정리할 예정이다.

| 지표 | 유효한 서열 한 개에 대한 계산식 |
| --- | --- |
| 소수성 비율 (%) | 소수성 아미노산 개수 ÷ 전체 길이 × 100 |
| 친수성 비율 (%) | 친수성 아미노산 개수 ÷ 전체 길이 × 100 |
| 비율 차이 (%p) | 소수성 비율 − 친수성 비율 |

예를 들어 소수성 비율이 60%, 친수성 비율이 40%라면 차이는 +20%p다. 음수이면 친수성 아미노산이 더 많고, 0이면 두 개수가 같다.

## 출력 명세

| 파일 | 포함할 서열 | 열과 기록 방식 |
| --- | --- | --- |
| `summary.csv` | 모든 입력 서열 | `input_order`, `id`, `status`, `total_length`, `hydrophobic_count`, `hydrophilic_count`, `hydrophobic_percent`, `hydrophilic_percent`, `ratio_difference_pct_points` |
| `detail.csv` | 유효한 서열 | `input_order`, `id` 뒤에 A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y 순서로 개수를 기록한다. 등장하지 않은 종류는 0으로 표시한다. |

두 CSV는 `input_order`로 연결한다. `summary.csv`의 상태는 `valid` 또는 `invalid`다. 유효하지 않은 레코드는 순번·ID·상태만 기록하고 모든 계산 열은 비워 둔다. 오류 사유 열은 두지 않는다.

| 저장할 막대그래프 | 가로축 | 세로축 | 표시 방식 |
| --- | --- | --- | --- |
| 서열 간 소수성·친수성 비율 비교 | 입력 순번과 ID | 비율 (%) | 유효한 서열마다 두 막대를 나란히 표시한다. |
| 서열 내 아미노산 20종별 개수 | 아미노산 한 글자 기호 20개 | 개수 | 유효한 서열마다 그래프 하나를 저장하고 제목에 입력 순번과 ID를 넣는다. |

유효하지 않은 서열은 그래프의 막대와 축 이름에서 모두 제외한다.

## 구현 및 검증 계획

FASTA는 Biopython으로 읽고, CSV는 Python 표준 라이브러리인 `csv`로 저장하며, 그래프는 matplotlib으로 그릴 예정이다.

- 같은 ID의 서열 두 개를 입력해 서로 다른 순번과 결과가 유지되는지 확인한다.
- 각 유효 서열에서 아미노산 20종별 개수의 합, 소수성 개수와 친수성 개수의 합, 전체 길이가 모두 같은지 확인한다.
- 공백·소문자·여러 줄을 포함한 서열이 정리되는지, 빈 서열이나 허용되지 않은 문자가 포함된 서열이 출력 규칙에 맞게 처리되는지 확인한다.
- 같은 입력 순번의 CSV 값과 그래프 막대 높이가 일치하는지 확인한다.

## 발표에서 설명한 활용 범위

서열별 소수성 경향을 빠르게 비교해 추가로 분석할 단백질을 고르는 데 활용할 수 있다. 이 분석은 아미노산 종류별 개수를 세므로 배열 순서가 달라도 조성이 같으면 같은 비율이 나온다. 단백질의 입체 구조나 기능을 판단하려면 추가 분석이 필요하다.
