## 왜 배열을 함께 볼까?

`LLLLSSSS`와 `LSLSLSLS`는 모두 류신(L) 4개와 세린(S) 4개로 이루어져 소수성 비율이 50%다. 하지만 L이 이어지는 최대 길이는 각각 **4와 1**이다. 이 두 예시는 프로그램이 조성과 배열을 따로 계산하는지 확인하는 손검산 기준이다.

## 기획 과정과 현재 단계

- **초기 기획 발표** — FASTA 파일에서 아미노산 조성을 읽고 소수성·친수성 비율을 비교하는 도구를 설계했다.
- **주제 확장** — 더 많은 입력 서열을 활용하기 위해 Aβ 변이 실험과 실제 환자 시료 연구를 검토했다. 실제 뇌척수액에서 검출된 서열의 특성을 설명하는 질문을 선택했다.
- **11월 23일 개정** — 주 비교를 ‘이번 측정에서 AD 시료에서만 검출’과 ‘세 집단 공통 검출’로 정했다. 중복 처리, 최장 연속 구간, 길이 필터와 검증 기준을 실행 명세에 추가했다.
- **다음 단계** — 보충표의 실제 열 구조와 소수성 분류표를 확인하고 구현한다. 이후 손검산과 실제 데이터 분석 결과를 기록한다.

## 데이터 출처와 해석 범위

공개 연구의 **Supplemental Table 7**을 사용하도록 설계했다. 집단별로 시료를 합쳐 측정했기 때문에 그래프의 점 하나는 펩타이드 서열 하나를 뜻한다. 결과는 해당 연구에서 검출된 서열의 특성으로 해석한다. [연구 논문 및 보충자료](https://pmc.ncbi.nlm.nih.gov/articles/PMC9240109/)
